# SkillSync — Project-Based Internship Platform

**SkillSync** is a web-based platform prototype designed to connect students and fresh graduates with companies through flexible, project-based internship opportunities.

The platform aims to bridge the gap between academic skills and industry needs by providing opportunities for students to gain practical experience, develop their portfolios, and improve their professional skills.

## 📌 Project Overview

SkillSync introduces a project-based internship marketplace where companies can publish short-term projects and find suitable talents, while students can explore opportunities that match their skills and interests.

The platform also includes a campus-oriented interface to support the connection between students, educational institutions, and companies.

## ✨ Main Features & Interfaces

The prototype includes several interfaces representing different user roles:

### 1. Student Dashboard
- Student dashboard interface.
- Project and opportunity exploration.
- Student profile and portfolio interface.
- Project-related information and activities.

### 2. Company Dashboard
- Company dashboard interface.
- Project management interface.
- Talent and applicant information.
- Project-related monitoring interface.

### 3. Campus Dashboard
- Campus dashboard interface.
- Student-related information.
- Academic and project monitoring interface.

### 4. Authentication Interface
- Login interface.
- Registration interface.

*Note: The features above describe the interfaces and intended user flows represented in the prototype. Not all features are connected to a working system.*

## 📥 How to Download

You can download the project directly from this repository:

1. Open the SkillSync GitHub repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open the extracted project folder in Visual Studio Code.

## 🚀 How to Run the Project

This project uses HTML, CSS, and JavaScript and can be previewed locally using Visual Studio Code and the Live Server extension.

1. Download and extract the project ZIP file.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if you haven't installed it.
4. Locate and open `index.html` in the root folder.
5. Right-click the file and select **Open with Live Server**.
6. The application will open in your default browser.

## ⚠️ Project Limitations

**This project is a front-end prototype and does not include a backend or database integration.**

Please note the following limitations:

- No real authentication or user account management.
- No backend processing or database storage.
- Some buttons and interface elements are visual components for demonstration purposes only.
- Some buttons and interactions are not yet functional.
- Some displayed information may use sample or dummy data.
- Features requiring server-side processing are not available in this prototype.

Therefore, this project is intended to demonstrate the user interface, visual design, and concept of the SkillSync platform rather than a fully operational web application.

## 🎯 Project Purpose

SkillSync was designed to provide a more flexible approach to gaining practical work experience through short-term, project-based opportunities.

By connecting students, educational institutions, and companies, the platform aims to help students build professional portfolios while supporting companies in finding potential talents.
